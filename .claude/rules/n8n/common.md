# workflow-with-n8n 공통 규칙

이 저장소의 모든 작업에 적용한다. HARD RULES 와 일반 규칙은 n8n 작업(n8n-mcp 툴 호출 포함)에 적용한다.

## HARD RULES

1. 삭제는 사용자가 **무엇을 삭제할지 명시해 삭제를 요청한 경우에만** 진행한다.
   - 요청에는 삭제 대상(워크플로우, 크리덴셜, 실행 기록, 데이터 테이블, 폴더 등)이 이름이나 ID로 특정되어 있어야 한다.
   - 대상이 특정되지 않았거나 모호하면 삭제하지 않고, 무엇을 삭제할지 먼저 묻는다.
   - 수정, 정리, 에러 해결 등 다른 작업 중에 삭제가 필요해 보여도 스스로 삭제하지 않고 삭제 요청을 받는다.
   - 삭제 요청을 받은 뒤에도 실행 직전에 삭제할 대상 목록을 보여주고 확인을 받는다.

## 일반 규칙

1. 작업 시작 전 `n8n_health_check`를 실행한다.

## 세션 역할

- 저장소의 문서·코드 변경은 `repo` 세션이 맡는다.
- n8n-mcp 호출과 워크플로우 생성·수정은 `mcp` 세션이 맡는다.
- 다른 세션에 맡길 일은 `.claude/tasks/<받을 세션>/YYYYMMDD-<작업명>.md` 작업지시서로 넘긴다.
- 받은 세션은 작업을 모두 끝내면 작업지시서를 지운다.
  - 끝: 작업지시서의 마지막 할 일까지. 저장소 변경이면 PR 병합과 버전 태그 push 까지
